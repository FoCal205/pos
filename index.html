Welcome to ShopDesk POS
ShopDesk is a complete Point of Sale system for local retail shops. It runs fully offline on your Windows computer — no internet subscription needed.
🛒
Point of Sale
Sell products, manage a cart, accept Cash & Mobile Money, and print receipts instantly.
📦
Product Management
Workers add products anytime — admin approves them. No extra cost, no tech person needed.
📊
Dashboard & Reports
Daily, weekly, monthly and yearly sales with charts, top products, and worker performance.
🎨
Fully White-Label
Change shop name, logo, colors, and business info. Works for any type of retail shop.
📋
What You Need First
Before running ShopDesk as a desktop app, install these on the computer. You only do this once ever.
1
Install Node.js (v18 or higher)
Node.js powers Electron. Download and install it once on this computer.
1. Open your browser and go to: https://nodejs.org 2. Click the big green "LTS" version button to download 3. Run the downloaded installer 4. Keep all the default options and click Next / Finish
⚠️ After installing Node.js, restart your computer before continuing to step 2.
2
Verify Node.js installed correctly
Open Command Prompt (Windows key → type cmd → Enter) and run both of these:
node --version npm --version
✅ You should see version numbers like v18.x.x and 9.x.x — that means it worked.
3
Extract the ShopDeskPOS folder
If you received a .zip file, right-click it and choose "Extract All". Put the folder somewhere easy to find, like your Desktop or Documents.
⚠️ Never run the app from inside a .zip file. Always extract it first.
⚙️
Installing & Running ShopDesk
Follow these steps in order. Steps 1 to 3 are done only once. After that, just use step 4 to open the app.
1
Open Command Prompt as Administrator
Press the Windows key, type cmd, then right-click "Command Prompt" and choose "Run as administrator". Click Yes on the permission popup.
⚠️ You must run as Administrator. Otherwise npm install may fail with a permission error.
2
Navigate to the ShopDeskPOS folder
In Command Prompt, type cd followed by the full path to the folder. For example:
cd C:\Users\YourName\Desktop\ShopDeskPOS
💡 Tip: You can drag the ShopDeskPOS folder directly into the Command Prompt window to paste its path.
3
Install dependencies (first time only)
This downloads Electron and all required files. Takes 1 to 3 minutes depending on internet speed.
npm install
✅ Done when you see a message like: "added 123 packages in 45s"
4
Launch the app (every time)
Every time you want to open ShopDesk, open Command Prompt in the ShopDeskPOS folder and run:
npm start
✅ ShopDesk opens in its own window. You can close Command Prompt after it launches.
🔐
First Login & Configuration
The app is running. Here is exactly what to do the very first time you open ShopDesk.
1
Log in as Admin
On the login screen, click the Admin tab on the right side. Use the default password to log in for the first time:
Password: admin123
⚠️ Change this password immediately after logging in. Go to Settings → Security → Change Password.
2
Set up your shop branding
Go to Settings → Branding to enter your shop name, tagline, and logo URL. Go to Settings → Business Info to add your address, phone, email, and hours. All of this appears on the login screen and every printed receipt.
3
Add your workers
Go to Staff → Add Worker. Enter each worker's name, select their role, and set their permissions. Workers log in by typing their name — no password needed for them.
4
Add your products
Go to Products → Add Product to add items to your catalog. You can also let workers add products from the POS screen during their shift — you approve them from the Products page.
📦
Build a Windows Installer (.exe)
Want to install ShopDesk on other computers without Node.js? Build a standalone .exe installer that anyone can run.
1
Run the build command
In Command Prompt (as Administrator), from inside the ShopDeskPOS folder, run:
npm run build
⚠️ Requires internet the first time. May take 5 to 10 minutes. Do not close Command Prompt while it runs.
2
Find your installer in the dist\ folder
When the build finishes, open the dist\ folder inside ShopDeskPOS. You will find a file like:
dist\ShopDesk POS Setup 2.0.0.exe
✅ Copy this .exe to any Windows PC and double-click to install. No Node.js needed on the other computer.
3
If the build fails
Try this fix and run the build again:
npm install --save-dev electron-builder npm run build
💡 If you see a "windows-build-tools" error, run: npm install --global --production windows-build-tools
